Project Name: FitLog – Workout Planner.

Project Description:

FitLog is a modern workout planning application built with Next.js and TypeScript. It allows users to explore workouts, save their favorite exercises, organize workout plans, and track their fitness activities through a user-friendly interface.

Technologies Used:

•⁠  ⁠Next.js
•⁠  ⁠React.js
•⁠  ⁠TypeScript
•⁠  ⁠Tailwind CSS
•⁠  ⁠Toaster and daisyUL


Key Features

1.⁠ ⁠Workout Library: Browse workouts with details such as duration, equipment, difficulty, and calories burned.

2.⁠ ⁠Workout Planning: Add workouts to a personalized workout plan.

3.⁠ ⁠Saved Workouts: Save favorite workouts for future reference.

4.⁠ ⁠Sorting Functionality: Sort workouts by duration, calories burned, and rating.

5.⁠ ⁠Workout Progress Tracking: Mark planned workouts as completed and manage the workout list.
